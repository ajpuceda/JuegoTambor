# 🥁 JuegoTambor — Tambor de Alonso

Juego web para móvil: un tambor azul **estilo Semana Santa** con el nombre **ALONSO** grabado en el parche.

- 👆 Toca el parche con los dedos → suena el tambor y los palillos golpean (multitáctil).
- 🥁 Botón **Redoble** → ráfaga de golpes con acento final.
- 🔔 Botón **Golpe lateral** → golpe seco en el aro (también tocando el lateral azul).
- 📳 Vibración en móviles compatibles.

## Cómo jugar

1. Activa GitHub Pages: **Settings → Pages → Branch: main, carpeta /(root) → Save**.
2. Abre <https://ajpuceda.github.io/JuegoTambor/> en el móvil.
